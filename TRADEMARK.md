# Preston-Check Trademark Policy

The name "Preston-Check", "PrestonCheck", the Preston-Check logo, and any
related word marks or design marks (collectively, the "Marks") are trademarks
of the Preston-Check project. The Apache 2.0 license that covers the source
code does NOT grant any trademark rights. This document defines what use of
the Marks is permitted and what requires explicit permission.

## Permitted use without permission

You may use the Marks in the following ways without asking:

- Stating accurately that your software uses, was scanned by, or is compatible
  with Preston-Check (e.g., "scanned by Preston-Check", "compatible with
  Preston-Check", "Preston-Check report enclosed").
- Linking to the official Preston-Check website, repository, or release artifacts.
- Displaying an official Preston-Check badge generated by the official badge
  endpoint (e.g., the score badge in your repository README).
- Discussing Preston-Check in articles, blog posts, conference talks, training
  materials, books, and educational content.
- Quoting the project name in news coverage, social media, and reviews.

## Use that requires permission

You must obtain written permission from the Preston-Check maintainers before:

- Using "Preston-Check" or any confusable variant in the name of a product,
  service, company, domain, GitHub organization, or package registry entry
  (npm, PyPI, Docker Hub, Homebrew, etc.).
- Distributing a fork or modified version of the project under any name that
  includes the Marks. Forks must use a clearly different name.
- Selling, sublicensing, or marketing any product or service under the Marks
  or under a confusable variant.
- Implying official endorsement, partnership, certification, or affiliation
  with the Preston-Check project where none exists.
- Using the Preston-Check logo on merchandise, advertising, or any commercial
  material.
- Registering domains, trademarks, social media handles, or business names
  containing "preston-check", "prestoncheck", or confusable variants in any
  jurisdiction.

## Forks and derivative works

You are explicitly permitted to fork, modify, and redistribute the source
code under the terms of the Apache 2.0 license. However, your fork MUST:

- Use a name that is clearly distinct from "Preston-Check" and not confusable
  with it.
- Remove the Preston-Check logo and any Preston-Check-specific branding from
  user-visible surfaces (CLI banner, report headers, badges).
- Clearly state that it is an unofficial fork and not endorsed by the
  Preston-Check project.
- Not represent itself as "Preston-Check" or as the official continuation of
  the project.

## Reporting violations

If you observe use of the Marks that you believe violates this policy, please
report it to the maintainers via the project's official communication channel.

## Changes to this policy

This policy may be updated from time to time. The current version is always
authoritative.
